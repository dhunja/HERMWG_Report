# HERMWG Report

Browser-viewable Archi HTML report of the BIZBOK_HERM model, published by the HERM Working Group of the Business Architecture Guild.

**View the report:** https://dhunja.github.io/HERMWG_Report/

Open the link in any web browser. No Archi software or GitHub account is needed. Until a report has been uploaded, the link shows this page.

**This repository is public.** Anything uploaded here can be seen by anyone with the link. Before each upload, check the model holds nothing that should stay internal, for example the HED Team Notes property. The model itself is kept in a separate private repository.

## For modellers: publishing a new report

Step 1. In Archi, open BIZBOK_HERM on the master branch and run Collaboration > Refresh Model.

Step 2. Use Archi's HTML report export and save the report to a new, empty folder.

Step 3. In GitHub Desktop, clone this repository. Replace everything in it except README.md with the exported files, so that index.html sits at the top level next to this README.

Step 4. Commit with a message that includes the date and the model's latest commit, then push. The site updates within a few minutes.

The report is a snapshot of the model when it was exported. Re-export and re-upload after the model changes.
