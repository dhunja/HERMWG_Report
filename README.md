# HERMWG Report

**Work in progress: working drafts only.** This report shows draft material produced by members of the HERM Working Group of the Business Architecture Guild while they collaborate. It is not an official draft, a published deliverable, or a position of the Business Architecture Guild. Content is incomplete, may contain errors, and may change or be removed at any time.

This is a browser-viewable Archi HTML report of the working group's BIZBOK_HERM model.

**View the report:** https://dhunja.github.io/HERMWG_Report/

Open the link in any web browser. No Archi software or GitHub account is needed.

**This repository is public.** Anything uploaded here can be seen by anyone with the link. Before each upload, check the model holds nothing that should stay internal, for example the HED Team Notes property. The model itself is kept in a separate private repository.

## For modellers: publishing a new report

Step 1. In Archi, open BIZBOK_HERM on the master branch and run Collaboration > Refresh Model.

Step 2. Update the "As of" date in the model's Purpose (select the model in the Models tree, then the Properties view) to today's date. Commit and publish that change in Archi.

Step 3. Use Archi's HTML report export and save the report to a new, empty folder.

Step 4. In GitHub Desktop, open your clone of this repository. Replace everything in it except README.md and .nojekyll with the exported files, so that index.html sits at the top level next to this README.

Step 5. Commit with a message that includes the date, then push. The site updates within a few minutes.

The report is a snapshot of the model when it was exported. Re-export and re-upload after the model changes.
